# NANO Updater

Updates NANO Industries devices from the browser (Chrome or Edge, WebUSB):
https://uranioempobrecido.github.io/NANO-Updater/

One folder per product, each published from its own firmware project (FX-DR:
`NANO-FX-DR/tools/web_updater/publish.sh`). Edit `index.html` here to list a new product.
