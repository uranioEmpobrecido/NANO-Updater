    If something goes wrong
    • The list is empty: check that the device is in update mode and that the cable goes straight to the computer, not through a hub. Try another cable: some only charge.
    • Windows: the first time you may need to install the WinUSB driver for the device (VID 0483, PID DF11) with Zadig (zadig.akeo.ie).
    • Linux: give the device permission with a udev rule: SUBSYSTEMS=="usb", ATTRS{idVendor}=="0483", ATTRS{idProduct}=="df11", MODE="0666"
    • If an update is interrupted, nothing is lost: put the device in update mode again and run it again.
    Advanced: flash another file

    Only if NANO Industries sent you a .bin file for this device. It is checked before flashing.
